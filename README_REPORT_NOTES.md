# Report Notes

The DOCX report accompanying this repository uses the same Week 1 problem framing and methodology.

## Important

The report's exploratory charts demonstrate the workflow with an illustrative dataset. Before a final
real-world submission, replace the demonstration dataset with a verified public dataset and rerun the
notebook/script.

## Suggested final data documentation

Record:

- Dataset title
- Publisher/department
- URL
- Download date
- Coverage period
- Licence/terms of use
- Variable definitions
- Missing-value handling
- Cleaning steps
- Any assumptions
